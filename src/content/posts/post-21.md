## 全新 Blueprint 蓝图设计语言
全局统一为 Blueprint 设计语言：全站直角卡片与方角边框、侧栏 subtle hatch 蓝晒纹理背景、加深可视卡片边框，视觉风格更加硬朗统一。

## 双栏布局重构与浮动导航
1. 顶部导航改为固定浮动式，悬浮于内容之上并带毛玻璃背景，滚动时始终可见；
2. 侧栏 PageAside 抽离为共享组件，全部页面统一使用，高度自动扣除顶部导航（96px）不再占满全屏；
3. 侧栏背景镂空大字标题装饰，仅在 2xl 超大断点下展示，避免中屏拥挤；
4. 首页独立侧栏同步升级，社交入口、系统状态与全局侧栏视觉对齐。

## 全局标题字体切换
标题字体由 Lexend 替换为经典衬线字体栈（Georgia / Noto Serif SC / 宋体系列），提升长文阅读质感。

## 多用户 Admin 面板
1. 新增多用户登录支持，bcrypt 密码哈希改用 base64 编码输出，规避环境变量展开问题；
2. 新增基于作者的访问控制（author-based ACL），不同作者只能管理自己的文章，并新增作者独立页面；
3. 新增 about.json / friends.json 等数据文件的 schema 化默认内容生成，初始化更稳定；
4. 修复 CMS 元数据日期输入框溢出、文章列表按文件名数字降序排序、项目数据数值类型被破坏等若干问题。

## 关于页重构
关于页配置迁移至 JSON 数据文件，并接入 CMS 可视化编辑器；新增个人数据矩阵（schedule / operator role 等）展示模块。

## 动态页增强
1. 动态内容支持富文本渲染；
2. 新增精确动态时间显示；
3. 超长动态自动折叠；
4. 修复刷新时 UI 闪烁问题。

## 页面过渡加载动画
重做页面切换加载动画：保留单个 Loader 全屏过渡、入口入场动画、导航期间拦截交互，修复切换闪烁与右键面板闪烁等细节问题。

## 移动端体验优化
1. 移动端隐藏侧栏统计与首页社交入口，仅保留核心信息；
2. 放大移动端侧栏标题字号；
3. 优化移动端顶部导航折叠菜单按钮样式。

## 性能与稳定性优化
1. 优化页面加载速度（FCP），减少强制重排（forced reflow）次数；
2. 移除冗余组件与样式：NumberTicker、SocialLink、ZoomImage、照片页（photos）等未启用代码；
3. 页面过渡期间兼容 `prefers-reduced-motion`，尊重系统减少动态偏好；
4. 导航时忽略指向当前 URL 的点击，避免无意义跳转；
5. 重写 README 为完整英文使用手册。

## 问题修复 (Both)
1. 修复侧栏身份标签数量限制、移动端联系方式展示异常；
2. 修复文章卡片垂直间距与其他页面不一致的问题；
3. 修复文章作者字段大小写不一致（统一为 refac7）；
4. 修复登录卡片多余阴影、侧栏装饰模糊、搜索结果无动画等问题；
5. 修复 TOC 移动端边框颜色与主题不匹配的问题；
6. 修复预览路径返回 404、Admin 面板 Toast 显示异常等问题。
